DESCRIPCIÓN DE COMPONENTES PRINCIPALES
=======================================

1. PriceSeries (src/models/price_series.py)
   - Representación estandarizada de series temporales
   - Cálculo automático de estadísticas
   - Métodos: sharpe_ratio(), annualized_return(), max_drawdown()
   - ~350 líneas de código

2. Portfolio (src/models/portfolio.py)
   - Gestión de carteras de inversión
   - Simulación Monte Carlo integrada
   - Métodos: report(), plots_report(), monte_carlo_simulation()
   - ~480 líneas de código

3. YahooFinanceExtractor (src/extractors/yahoo_finance.py)
   - Extracción de datos de Yahoo Finance
   - Soporte: acciones, índices, ETFs, crypto, forex
   - Descarga concurrente de múltiples símbolos
   - ~250 líneas de código

4. DataCleaner (src/processors/cleaner.py)
   - Limpieza y preprocesado de datos
   - Manejo de valores faltantes y outliers
   - Alineación de múltiples series
   - ~250 líneas de código

5. DataValidator (src/processors/validator.py)
   - Validación de calidad de datos
   - Conversión de inputs arbitrarios
   - Generación de reportes de calidad
   - ~350 líneas de código

6. MarkdownReporter (src/reporting/markdown_report.py)
   - Generación de informes en Markdown
   - Análisis detallado de carteras
   - Advertencias y recomendaciones
   - ~300 líneas de código

7. PlotGenerator (src/reporting/plots.py)
   - Generación de visualizaciones profesionales
   - 7+ tipos de gráficos diferentes
   - Integración con matplotlib y seaborn
   - ~550 líneas de código
